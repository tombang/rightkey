RightKey 1.4.0 adds directory marks to Finder's context menu.

- Mark up to 20 folders and jump to any of them from another Finder window.
- Rename, reorder, and delete marks in the RightKey settings window.
- Keep a mark when its folder is deleted, renamed, or moved. Choosing it explains that the saved path is gone, and you can keep or remove the mark.
- Keep marks for disks that are not connected. Unmounted disks are not treated as deleted, and removing missing marks leaves them in place.
- Store the path rather than a file identity. RightKey does not search for another folder with the same name.
- Save marks only on this Mac, in ~/Library/Application Support/RightKey/DirectoryMarks.json.

macOS 13 or later, Apple Silicon and Intel. The app uses a local ad hoc signature; it is not Developer ID signed or notarized.

Download the ZIP and verify its SHA-256 file. See the README for installation and Finder extension activation.
