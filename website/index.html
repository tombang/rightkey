A FEW GOOD QUESTIONS.

遇到其他问题？
到 GitHub 告诉我们 ↗

RightKey 是免费的吗？

是。RightKey 免费使用，源码以 MIT 许可证公开。你可以查看、修改和参与项目。

安装后，右键菜单没有出现怎么办？

先确认 RightKey 位于「应用程序」中，并已在系统设置中开启 Finder 扩展。随后按住 Option 点击程序坞中的 Finder，选择「重新开启」。扩展启用与文件夹访问权限是独立设置。

剪切之后，应该怎么粘贴？

在源文件上选择「剪切」，进入目标目录后选择「粘贴（移动剪切项）」或「移动到这里」。Finder 自带的「粘贴项目」和 ⌘V 保持系统原有行为。源文件在成功移动之后才会移除。

Word 和 Excel 模板怎么添加？

打开 RightKey 的「文件模板」页面，点击「导入文件…」，选择有效的 Word 或 Excel 文件。以后从「新建文件 → 自定义模板…」创建。模板会保存内容副本，单个模板上限为 10 MB。

会上传我的文件或模板吗？

RightKey 的文件操作与模板存储都在本机完成，无需注册账户。自定义模板保存在 ~/Library/Application Support/RightKey/Templates.json，不会包含在应用发布包中。

会覆盖已有的同名文件吗？

不会。新建、复制和移动遇到同名项目时，RightKey 自动追加「(2)」「(3)」等编号。部分移动失败时，会提示原因并保留未完成的剪切项供重试。
