RightKey 1.4.1 adds a double-click installer.

- Unzip the release and double-click 安装 RightKey.command.
- The installer removes an older RightKey, installs this version, and keeps templates and directory marks.
- If macOS blocks the installer, Control-click it and choose Open. No Terminal commands are required.
- Finder restarts automatically. Enable the Finder extension in RightKey if macOS asks.

macOS 13 or later, Apple Silicon and Intel. The app uses a local ad hoc signature; it is not Developer ID signed or notarized.
