# Security Policy

## Reporting a vulnerability

Please do not publish personal file paths, clipboard contents, access tokens, signing certificates, or other sensitive data in a public issue.

For a suspected vulnerability, use GitHub's private security advisory workflow for this repository. If that channel is unavailable, contact the repository owner privately through the GitHub profile and include:

- the affected version or commit;
- a concise description of the impact;
- reproduction steps that use synthetic files; and
- any proposed mitigation.

## Scope

RightKey performs local Finder file operations and uses a Finder extension with App Sandbox and user-selected file access. Reports involving unexpected file access, unsafe request handling, clipboard data exposure, or unintended file replacement are especially useful.
